# 말랑기록 (Mallang Record)

우리 아이 목소리로 움직이는 그림책. 두 돌 전후 아이가 말한 단어를, 그림책 그림이 목소리에 맞춰 움직이는 세로 영상으로 남기는 모바일 웹앱(PWA)입니다.

- 진짜 사람 입·눈 사진을 합성하지 않습니다. 올린 그림은 다시 그리지 않고 그대로 늘이기·기울이기·이동만 합니다.
- 기본 그림 23종은 수채화 질감의 귀여운 그림체입니다. 그림 속 입은 그림체와 같은 색·굵기로 앱이 그리며, 목소리 크기에 맞춰 열립니다 ("입 움직이기"를 끄면 미소로 고정).
- 녹음, 그림, 영상 만들기는 모두 기기 안에서 처리합니다. 서버가 없고 회원가입도 없습니다.

---

## 1. 휴대폰에서 바로 쓰기 (개발 지식 없이)

iPhone에서 녹음하려면 앱이 **https 주소**에 올라가 있어야 합니다. 가장 쉬운 방법은 Netlify Drop입니다.

1. 컴퓨터에서 `mallang-record-dist.zip`의 압축을 풉니다. `dist` 폴더가 나옵니다.
2. 브라우저로 **https://app.netlify.com/drop** 에 들어갑니다. (무료 계정으로 로그인해 두면 주소가 사라지지 않고 계속 유지됩니다)
3. `dist` 폴더를 통째로 화면에 끌어다 놓습니다.
4. 잠시 뒤 `https://무언가.netlify.app` 주소가 생깁니다.
5. iPhone **Safari**에서 그 주소를 엽니다. (카카오톡에서 링크를 누르면 카톡 안 브라우저가 열려 마이크가 막힙니다. 길게 눌러 "Safari로 열기"를 쓰세요.)
6. Safari 아래쪽 공유 버튼 → **홈 화면에 추가**. 이제 앱처럼 열리고 기록이 더 안전하게 보관됩니다.

> Vercel, Cloudflare Pages, GitHub Pages 등 다른 정적 호스팅도 `dist` 폴더를 그대로 올리면 됩니다.

## 2. 컴퓨터에서 실행하기 (개발용)

필요한 것: Node.js 18 이상

```bash
npm install
npm run dev        # http://localhost:5173 에서 열림 (같은 와이파이의 휴대폰은 화면에 표시되는 Network 주소로)
npm run build      # 배포용 dist 폴더 만들기
npm run build:single && node scripts/make-preview.mjs   # 파일 한 장짜리 미리보기
```

휴대폰에서 개발 서버(http://192.168...)로 열면 https가 아니라서 **마이크가 막힙니다**. 휴대폰 마이크 테스트는 위 1번처럼 https 주소에 올려서 하세요. (또는 `npx vite --host` + `ngrok http 5173` 같은 터널)

## 3. 사용법

**단어 기록하기**
1. 첫 화면 → 새 단어 기록하기 → 그림 선택
2. 빨간 버튼 → 마이크 허용 → 아이가 "사과!" → 다시 눌러 멈추기
3. 들으면서 미리보기 → 다시 녹음 또는 **기록 저장**
4. 편집 화면에서 움직임·자막·제목·날짜·길이·그림 바꾸기 → **영상 만들기**
5. iPhone: "사진 앱에 저장 · 공유" → **동영상 저장**

**이미 찍어 둔 영상·음성 쓰기**: 녹음 화면의 "음성·영상 파일 불러오기" → 사진첩 영상 선택. 소리만 꺼내 쓰고 화면(아이 얼굴)은 저장하지 않습니다.

**내 그림 올리기 / 바꾸기**
- 내 그림 라이브러리 → 그림 누르기 → "내 그림으로 바꾸기" (원래 그림으로 되돌리기 가능)
- "+ 새 단어": 목록에 없는 단어와 그림 추가
- "여러 장 한꺼번에 올리기": 파일 이름이 단어 이름이 됩니다 (`사과.png` → 사과). 같은 이름의 기본 그림은 자동 교체 (끌 수 있음)
- 크기·좌우·위아래 슬라이더 또는 미리보기에서 손가락으로 끌어서 위치 조정
- 흰 배경 JPG는 "단색 배경 지우기" → 미리보기 확인 → 적용 (원본 보관, 언제든 되돌리기)
- 투명 배경 PNG·WebP를 가장 권장합니다

**아이가 한 말**: 기록 편집 화면 맨 위에 아이가 실제로 한 말을 적어요(예: 그림은 "돌고래", 아이 말은 "물꼬기쩜뿌"). 그림 이름과 따로 저장되고, 이전 기록 카드와 그림책에 이 말이 나와요. 예전 기록은 자막 글자를 그림 이름과 다르게 바꿔 뒀다면 그걸 아이 말로 보여줘요(저장된 기록은 바꾸지 않음).

**그림책으로 잇기**: 이전 기록 보기 → 여러 개 잇기 → 순서대로 선택 → 그림책 화면. 책 모양 3가지 중 고르면(마지막 선택을 기억) 미리보기와 영상이 똑같이 바뀌어요.
- 한 페이지: 그림 위·아이 말 아래, 오른쪽 아래 모서리가 접히며 왼쪽으로 넘어감
- 좌우 펼친 책: 왼쪽 그림·오른쪽 아이 말, 오른쪽 장이 책등을 축으로 넘어감(원근감)
- 위아래 펼친 책: 위 그림·아래 아이 말, 아래 장이 고리를 축으로 위로 넘어감
- 아이 말은 목소리가 나오는 동안 한 글자씩 둥근 글씨(주아)로 나타나고, 목소리가 끝나면 0.7초 쉰 뒤 책장이 넘어가요. 순서 목록의 ✏️로 아이 말을 바로 고칠 수 있어요.

**백업**: 설정·백업 → 백업 파일 받기 (그림·녹음 포함 JSON). 휴대폰을 바꾸기 전에 꼭 받아 두세요.

## 4. 움직임 방식

**캐릭터 움직임**: 기본 그림마다 생김새·성격에 맞춘 "대표 동작"이 기본으로 연결돼 있습니다. 동작은 준비 → 동작 → 착지 → 여운 순서로 이어지고, 소리가 끝나면 제자리로 돌아와 쉽니다(달·풍선·이불만 조용할 때도 아주 잔잔히 움직임).

| 방식 | 기본 연결 | 대표 동작 |
|---|---|---|
| 통통 | 사과 | 낮고 짧은 공 튀기기, 닿을 때 납작 |
| 탱글 | 귤 | 소리마다 빠르게 탱글 떨렸다 멈춤 |
| 대롱 | 포도 | 위쪽 꼭지를 축으로 송이째 천천히 흔들 |
| 묵직 | 수박 | 큰 소리에만 살짝 들렸다 쿵(먼지 폴폴), 거의 안 뜀 |
| 살랑춤 | 바나나 | 아래를 축으로 좌우로 춤 |
| 오뚝이 | 가지 | 소리마다 좌우 번갈아 기우뚱했다 다시 서기 |
| 쑥쑥 | 당근 | 소리만큼 솟고, 소리가 끝나면 흔들리며 자리 잡기 |
| 톡톡 | 옥수수 | 짧은 소리마다 팝콘처럼 톡, 길게 말하면 바르르 |
| 두근 | 딸기 | 소리마다 "두-근" 두 번 커짐, 시작할 때 하트 |
| 데굴 | 도토리 | 굴러갔다 굴러 돌아오기 |
| 깡총 | 토끼 | 웅크림 → 높이 깡총 → 착지 납작 → 통 (사과보다 높고 드묾). 소리가 길게 이어지면 1.3초 간격으로 다시 깡총 |
| 뒤뚱 | 곰 | 양발로 번갈아 디디며 뒤뚱뒤뚱 |
| 기지개 | 고양이 | 길게 말하면 몸을 쭉 늘이고, 짧은 소리엔 고개 갸웃 |
| 신나 | 강아지 | 엉덩이 쪽을 축으로 빠르게 흔들, 크게 말하면 살짝 뜀 |
| 끄덕 | 소 | 얼굴 쪽으로 천천히 끄덕 (음절마다 끄덕이지 않음) |
| 쪼르르 | 다람쥐 | 앞으로 쪼르르 → 멈춰 고개 갸웃 |
| 첨벙 | 돌고래 | 물 위로 포물선 점프(오를 땐 머리 들고 내려올 땐 숙임), 물보라 |
| 흔들 | 달 | 요람처럼 일정한 박자로 흔들, 목소리에 폭만 커짐 |

바닥 위치와 회전 중심은 이미지 테두리가 아니라 투명 여백을 뺀 실제 그림 기준이라, 그림자가 그림 바로 아래에 붙습니다(직접 올린 그림도 같음). 캐릭터마다 강도·속도 조절의 최대치가 달라서(수박·달·소처럼 무거운 캐릭터는 크게 올려도 덜 움직임) 성격이 유지됩니다. 비행기·유모차·소·돌고래는 그림이 바라보는 쪽으로 나아갑니다.

**기본 움직임**: 직접 올린 그림이나 원하는 그림에 자유롭게 고를 수 있습니다.

| 방식 | 기본 연결 | 움직임 |
|---|---|---|
| 말랑 | 토마토 | 목소리가 커지면 살짝 납작(약 96~104%) → 탄성 있게 복원 |
| 콩콩 | (직접 고르기) | 소리가 툭 커질 때마다 작은 점프, 착지 그림자 |
| 둥실 | 풍선 | 조용할 땐 조금 낮은 자리에서 잔잔히, 목소리가 나면 아래에서 위로 둥실 날아오르고(위쪽 한계에서 멈춤) 끝나면 천천히 내려옴, 소리 파동 |
| 날아가기 | 비행기 | 앞으로 나아가며 기수를 들고, 바람선·구름 |
| 물결 | (직접 고르기) | 몸이 물결처럼 휘며 헤엄, 물결선·물방울 |
| 포근 | 이불 | 숨 쉬듯 부풀고 가장자리가 살랑, 작은 하트 |
| 굴러가기 | 유모차 | 앞으로 데굴, 먼지 |

새 그림을 올리면 이름을 보고 어울리는 움직임을 자동으로 골라 줍니다 (예: "기린" → 끄덕, "햄스터" → 쪼르르).

조절: 강도, 속도, 목소리 반응 민감도, 효과선, 반짝임, (기본 그림) 입 움직이기.

**부위별 움직임 (토끼·강아지·돌고래·곰·고양이·소·다람쥐)**: 그림을 다시 그리지 않고, 원본을 바탕·부위·눈 조각으로 나눠(`scripts/make-rig.py`) 부위마다 따로 움직입니다. 토끼는 귀가 벌어지며 출렁이고 꼬리 방울이 달랑, 강아지는 늘어진 귀가 펄럭이고 꼬리가 살랑, 돌고래는 꼬리 쪽 몸이 휘며 물을 찹니다. 곰은 동그란 귀가 쫑긋, 고양이는 S자 꼬리가 느긋하게 살랑이고 소리가 나면 귀가 움찔(조용할 땐 가끔 혼자 쫑긋), 소는 옆으로 난 귀가 팔랑이고 꼬리가 휙휙, 다람쥐는 큰 꼬리가 출렁이고 귀가 움찔. 몸 뒤에 있는 꼬리는 몸보다 먼저 그려서 몸에 가려집니다. 귀처럼 선을 따라 자른 부위는 그 선에서 멀어질수록 휘어서 자른 자리에 틈이 생기지 않습니다.  부위는 뿌리를 축으로 휘어서 바탕과 이음새가 생기지 않습니다.

**눈 깜빡임 (기본 그림 23종 전부)**: 3~4초마다 자연스럽게, 가끔은 두 번 연달아 깜빡이고, 크게 말하면 살짝 웃는 눈이 됩니다. 원래 눈 자리는 얼굴색 덮개로 가리고, 같은 눈을 세로로 접었다 펴며, 다 감기면 그림체와 같은 색의 곡선을 그립니다. 몸이 물결치는 움직임에서도 눈이 함께 따라갑니다. 캐릭터마다 깜빡이는 박자가 달라요.

**입 움직이기**: 기본 그림은 원래 그려져 있던 미소를 지운 그림 + 입 위치 정보로 저장되어 있습니다. 앱이 그 자리에 같은 색의 입을 그리고, 소리 크기만큼 열고 닫습니다. 음절을 알아듣는 것은 아니라서 "사"와 "과"를 구분한 입 모양은 아닙니다. 직접 올린 그림에는 입을 그리지 않습니다.

**음성 분석 방식**: 소리 세기(RMS) → dB → 잡음 바닥 + 민감도로 노이즈 게이트 → 빠른 상승/느린 하강 스무딩 → 말 시작·멈춤 감지(히스테리시스) → 소리가 툭 커지는 순간 감지 → 감쇠 스프링(탄성). **음절이나 발음 내용은 인식하지 않습니다.** 그림은 소리의 크기와 리듬에만 반응합니다.

## 5. 구조

```
src/
  lib/
    builtins.ts   기본 그림 23종 목록 + 각 그림의 입 위치·색
    rigs.ts       부위별 움직임 정의 (부위 뿌리·방향·움직임 방식, 눈 위치)
  assets/art/     기본 그림 (입을 지운 수채화 WebP, 768px)
  assets/rig/     부위별 움직임용 조각 (scripts/make-rig.py로 생성: 바탕·귀·꼬리·눈)
    motion.ts     목소리 → 움직임 신호 (게이트, 스무딩, 발화·onset 감지, 스프링, 동작 순서용 "마지막 소리 이후 시간")
    poses.ts      움직임 방식별 몸 자세 계산 (대표 동작, 캐릭터별 강도·속도 상한, 이동 범위 제한)
    render.ts     9:16 장면 그리기 (자세 적용, 부위·눈, 효과, 자막) — 화면과 영상이 같은 코드
    timeline.ts   클립 이어붙이기·자르기, 시각별 장면
    book.ts       그림책 잇기 (책 모양 3가지, 한 글자씩 자막, 책장 넘김) — 미리보기·영상 공용
    exporter.ts   캔버스 + 원래 목소리 → MediaRecorder 영상 (MP4 우선, 오디오 시계로 동기화)
    audio.ts      녹음 형식 선택, 디코딩, WAV, 영상에서 소리 꺼내기
    images.ts     그림 준비(종이 질감), 업로드 정리, 단색 배경 지우기
    db.ts         IndexedDB 저장
    env.ts        카톡·인스타 앱 안 브라우저, 미리보기 프레임, https 확인 + 쉬운 오류 안내
    backup.ts     백업/복원
  screens/        Home, Library(그림 선택·관리), Recorder, ClipEditor, Archive, Compose, Settings
public/           manifest, sw.js(오프라인), 아이콘, _headers(마이크 허용 정책)
```

## 6. 영상 형식

- iPhone Safari(iOS 14.5+): MP4(H.264/AAC)로 저장 → 사진 앱에 저장 가능
- Android Chrome: 기기에 따라 MP4(H.264) 또는 MP4/WebM(VP9)
- MP4를 못 만드는 브라우저는 저장 화면에 "WebM으로만 저장돼요"라고 미리 알립니다.
- 서버 측 FFmpeg 변환은 **만들지 않았습니다** (아이 목소리를 서버로 보내지 않기 위해). 필요하면: 사용자 동의 화면 → 업로드 → `ffmpeg -i in.webm -c:v libx264 -pix_fmt yuv420p -c:a aac out.mp4` → 응답 후 즉시 삭제하는 작은 서버를 추가하는 방식으로 확장할 수 있습니다.
